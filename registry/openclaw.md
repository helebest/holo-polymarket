# OpenClaw / ClawHub distribution

The skills use the AgentSkills-compatible folder format, so OpenClaw can load this
repository's canonical `skills/` directory directly, and ClawHub can publish each
skill individually. The `holo-polymarket` plugin wrapper also ships
`openclaw.plugin.json` under `plugins/holo-polymarket/` for plugin-based loading.

## ClawHub (skill registry)

The ClawHub CLI is distributed via npm:

```bash
npm i -g clawhub          # or: npx clawhub@latest <command>
clawhub login             # GitHub-based auth (clawhub login --device for headless)
```

Publish individual skills (skills are plain AgentSkills folders — no extra
manifest is required):

```bash
clawhub skill publish skills/polymarket-query
clawhub skill publish skills/polymarket-trade
```

Install / discover:

```bash
clawhub search "polymarket"
clawhub install <publisher>/polymarket-query   # installs into ./skills
```

## OpenClaw

OpenClaw discovers skills at, in precedence order, `<workspace>/skills`,
`<workspace>/.agents/skills`, `~/.agents/skills`, `~/.openclaw/skills`, then
bundled and plugin skills. Options:

1. Copy or symlink folders under `skills/` into an OpenClaw skills directory, or
   use `openclaw skills install <slug>` / `--global`.
2. Load the plugin wrapper via `plugins/holo-polymarket/openclaw.plugin.json`
   (its `skills` array points at `./skills`).
3. Publish the OpenClaw plugin archive generated by `holo-polymarket-build`.

This repository does not keep a separate OpenClaw workspace copy. The local
plugin `skills/` directory is generated from the canonical `skills/` by
`holo-polymarket-sync-plugin`.
